# CLOCK IN Competition Baseline

MWA Lab is being built for CLOCK IN — Solana Mobile Hackathon 2026.

Primary product identity:

MWA protocol debugger + deterministic failure simulator.

Competition build scope remains:

- Android;
- Kotlin;
- Jetpack Compose;
- Solana Devnet only;
- no production-wallet functionality;
- no mainnet signing;
- no backend;
- no AI chatbot;
- no unrelated DeFi/NFT/staking features.

The engineering priority is to make MWA failures visible, reproducible, and
fixable.
